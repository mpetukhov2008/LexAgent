# Ресурсы интерфейса

Все ресурсы поставляются локально: при открытии страницы нет запросов к CDN шрифтов,
маркетплейсам или сайту-референсу.

| Ресурс | Происхождение |
|---|---|
| `fonts/Manrope.woff2` | Manrope, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), полный variable-шрифт с кириллицей, преобразован из TTF в WOFF2 |
| `fonts/Unbounded.woff2` | Unbounded, [Google Fonts](https://github.com/google/fonts/tree/main/ofl/unbounded), полный variable-шрифт с кириллицей, преобразован из TTF в WOFF2 |
| `fonts/*-OFL.txt` | Полные лицензии SIL Open Font License 1.1 и сведения об авторах |
| `brands/wildberries.svg`, `brands/ozon.svg` | Компактные векторные обозначения WB/OZON для этого интерфейса: контуры букв Manrope на цветных плашках. Это стилизованные значки, а не официальный комплект логотипов площадок |
| `moscow-city.svg` | Авторский векторный силуэт из предыдущей версии проекта |

Шрифты сжаты fontTools/Brotli только при подготовке ресурсов; эти инструменты не
нужны для запуска приложения. Лицензии сохранены рядом с файлами.
Обозначения площадок используются рядом с названиями источников спора.

По пожеланию владельца проекта визуальным ориентиром служит
[Nuclear IT Hack](https://nuclearhack.mephi.ru/): выразительные заголовки и разделение
смысловых блоков. Структура кабинета, палитра, рисунок города и код приложения свои;
ресурсы сайта-референса не копировались.
