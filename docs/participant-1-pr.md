# Агент первичного разбора споров о карточках маркетплейсов

Юрист может ввести фабулу и тексты документов, получить карточку исходных сведений с точными цитатами и ответить на уточнения. Если данные расходятся, сохраняются обе версии. Следующие агенты получают контракт результата первого этапа.

Реализованы инструментальный агент, адаптер Alice AI / Yandex AI Studio, автономная демонстрационная политика, FastAPI, SQLite, постоянная очередь с арендой и контрольными точками, история запусков, форма и JSON-экспорт. Секреты задаются через `.env` и не передаются клиенту.

Проверка: автоматические тесты агента, API, очереди, восстановления, ограничений и адаптера Yandex; сквозные сценарии в браузере. Подробные результаты — `reports/participant-1-verification.md`.

Ограничения: живой Yandex API проверен на одном синтетическом сценарии 04.11.2026; demo не использует модель, юридическое качество требует отдельной оценки. PostgreSQL, авторизация, OCR, поиск судебных дел и агенты 2–6 не входят в эту реализацию.
