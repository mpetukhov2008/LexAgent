# Предложение команде

Делаем «Перспективу дела» — сервис поиска похожей арбитражной практики по спорам
о копировании фото, инфографики и текстов карточек маркетплейсов. Юрист вводит
ситуацию и получает объяснимую подборку с цитатами, различиями и ограничениями.

Стек: Python, FastAPI, PostgreSQL, LangChain + GigaChat-2-Pro, Parser API,
pypdf, HTML/CSS/JavaScript, pytest/Ruff/Playwright. Полнотекстовый и векторный
поиск, OCR и анализ инстанций — следующие задачи команды.

1. Участник 1 — агент разбора, backend, очередь, PostgreSQL, интеграция и форма ввода.
2. Участник 2 — агент-исследователь, источники, PDF/OCR и история инстанций.
3. Участник 3 — агент поиска, запросы, индекс, гибридный поиск и фильтры.
4. Участник 4 — агенты сравнения и отчёта, объяснение применимости и экран результатов.
5. Участник 5 — агент-критик, контрпримеры, разметка с юристом и измерение качества.

У каждого свой агент с инструментами, ограничениями, результатом и тестами.
Основа участника 1 уже реализована, остальные роли подключены на базовом уровне.
Доступ Parser API требует решения проблемы ключа 40301; локальный импорт работает.
