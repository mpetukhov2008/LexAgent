# Участник 1: материалы предварительной защиты

## Что сделано

Реализован отдельный агент разбора исходной ситуации по спорам о контенте маркетплейсов. Он использует пять инструментов: список источников, чтение документа, запись сведений с цитатой, запрос уточнения и завершение. В режиме Yandex следующий инструмент выбирает Alice AI. Код проверяет допустимость действия, цитату, структуру результата, лимиты и условия завершения.

Дополнительно реализованы FastAPI backend, постоянная база SQLite, очередь заданий с восстановлением, журнал событий, идемпотентное создание заданий, форма ввода, тексты документов, уточнения, история и JSON-экспорт. Локальное приложение рассчитано на одного пользователя.

## Как запустить

Открыть PowerShell в `C:\Users\Kate\Documents\ChatGPT\case-prospects`:

```powershell
.\run.ps1
```

Страница: http://127.0.0.1:8010. Swagger: http://127.0.0.1:8010/docs.

Если PowerShell не разрешает запуск скриптов, не требуется менять системную политику — используйте прямую команду:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8010
```

На другом компьютере с Python 3.10+ сначала установить зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
```

Файл `requirements.lock.txt` фиксирует версии, проверенные при подготовке. Он включает инструменты тестирования. Интернет нужен для первой установки и для Yandex, но не для локального деморежима.

## Подключение Алисы

Локальный `.env` настроен предоставленными реквизитами и исключен из Git. При переносе создать его из `.env.example` и заполнить:

```dotenv
YANDEX_API_KEY=секретный_ключ_сервисного_аккаунта
YANDEX_FOLDER_ID=идентификатор_каталога
YANDEX_MODEL_URI=
ENABLE_YANDEX=true
```

По умолчанию используется URI `gpt://<каталог>/aliceai-llm`. При необходимости указать полный URI доступной в каталоге модели. Приложение вызывает Yandex AI Studio, а не пользовательский чат Алисы. Наличие подписки на пользовательскую Алису само по себе не является настройкой API.

Остановить сервер Ctrl+C и запустить снова. Выбрать «Alice AI · Yandex API», использовать синтетический пример и подтвердить отправку его текстов. Все тексты выбранного запуска передаются в Yandex; demo работает локально. Ключ не возвращается через API приложения и не попадает в репозиторий. Заголовок `x-data-logging-enabled: false` запрашивает отключение журналирования у провайдера; это не локальная обработка данных.

## Демонстрация за 4–5 минут

1. **Задача, 30 секунд.** «Юрист начинает с неполного описания спора. Мой компонент превращает его в карточку исходных сведений. Он не оценивает вероятность победы и не ищет судебные дела — это следующие агенты команды».
2. **Полные сведения, 60 секунд.** Нажать «Полные сведения», дождаться заполнения формы, затем «Разобрать ситуацию». Показать шесть полей, различие источников, точную цитату и журнал `list_documents → read_document → record_facts → finish`.
3. **Пробелы, 60 секунд.** Выбрать «Пробелы», дождаться заполнения, запустить. Показать три вопроса: права, способ размещения, дата. Заполнить их и нажать «Сохранить уточнения». Появится новая версия; предыдущая останется в истории.
4. **Противоречие, 60 секунд.** Выбрать «Противоречие», запустить. В описании указано автодобавление, в учебном документе — загрузка продавцом. Показать оба источника и предупреждение. Система не выбирает удобную версию без проверки.
5. **Надежность, 30 секунд.** Показать тесты, экспорт JSON и историю. Объяснить контрольную точку и блокировку повторного исполнения. В тестах моделируется сбой процесса и перехват задания другим worker.

Все три примера синтетические. Деморежим разбирает явно подписанные поля, а не произвольный русский текст. В отличие от него API-режим предназначен для свободного текста; качество на живой модели требует отдельной проверки.

## Короткое выступление

«Я реализовал компонент первичного разбора ситуации. На вход поступают фабула, позиция клиента и тексты документов. Агент выбирает инструменты чтения и извлечения, сохраняет каждое сведение с источником и точной цитатой. Если данных недостаточно, он формирует вопросы; если источники расходятся, сохраняет обе версии. Результат передается следующему участнику как структурированный JSON.

Кроме агента, реализованы API, хранение заданий, журнал и восстановление после прерывания. Повторный запрос с тем же ключом не создает новое задание. Контрольная точка сохраняется в одной транзакции с событием. На предварительной защите показываем локальный сценарий и тесты; подключение к Alice AI подготовлено отдельно».

Эту формулировку можно использовать только после изучения кода и проверки участником. Исходная реализация подготовлена при помощи Codex; личный вклад участника — понимание, проверка, доработка и защита. Не приписывать автоматически весь сгенерированный код самостоятельной разработке без раскрытия использования AI согласно правилам учебного проекта.

## Ответы на вероятные вопросы

**Где здесь агент?** В API-режиме модель выбирает следующий инструмент по результатам предыдущих действий. Код ограничивает его полномочия и проверяет результат. Оркестратор и база не выдаются за дополнительных агентов. Demo — отдельная воспроизводимая политика по правилам, а не доказательство качества LLM.

**Как предотвращаете выдуманные факты?** Нельзя ссылаться на непрочитанный источник или несуществующую цитату. Но дословная цитата не гарантирует правильности интерпретации; это проверяют юрист и будущий агент-критик. Статусы «со слов клиента» и «указано в документе» не означают «установлено судом».

**Почему SQLite, а не PostgreSQL?** Для автономной предварительной защиты выбран локальный файл, не требующий Docker. Транзакции, уникальные ключи и аренда заданий реализованы. PostgreSQL остается дальнейшим этапом многопользовательской версии; перенос потребует отдельного адаптера и проверки конкурентности.

**Что происходит при сбое?** При нормальной остановке задание возвращается в очередь. При аварии новый worker подхватит его после истечения 30-секундной аренды. Сохраненные инструментальные действия не повторяются; внешний запрос модели при аварии до сохранения ответа может повториться и повторно тарифицироваться. Гарантия exactly-once для внешнего API не заявляется.

**Что еще не готово?** Агенты других участников, поиск КАД, PDF/OCR, юридическая оценка качества, полноценная аутентификация и многопользовательский сервис. Живой вызов Yandex требует ключа и проверки. Режим записи «Подтверждено судом» не реализуется этим агентом.
