# Довод: интерфейс 0.6

10 ноября 2026. Команда — «Поколение Степика». Техническое имя репозитория LexAgent
сохранено для совместимости. Старые PR №1–4 интегрированы в main.

## Оформление

Manrope используется для форм и длинного текста, Unbounded — для крупных заголовков
и названия. Полная кириллица и variable-веса поставляются как локальные WOFF2;
лицензии находятся рядом. Небольшие векторные обозначения WB/OZON показаны рядом
с названиями площадок на входе, в кабинете и в сведениях о площадке из результата.
Значки не заменяют исходный текст и не мешают чтению экранными дикторами.

Сохранены Москва-Сити, синие/мятные акценты, тёмная тема по умолчанию и светлая
по выбору. Выбор темы сохраняется в localStorage. Интерфейс адаптируется к телефону,
поддерживает клавиатуру и prefers-reduced-motion. Референс оформления — Nuclear IT Hack;
его код, графика и шрифты не копировались.

## Актуальные возможности в кабинете

Под панелью агентов показаны сохранение PDF, OCR, история инстанций, смысловая
проверка и контраргументы. Кнопка «Проверить готовность» открывает «Подключения».

В подключениях три отдельные карточки:

- GigaChat: наличие ключа и отдельная проверка авторизации. Это не проверка генерации.
- КАД и Банк решений: доступ через Parser API, отдельные результаты двух сервисов.
  Проверка использует два внешних обращения; без ключа кнопка отключена.
- Оригиналы PDF и OCR: локальная проверка Tesseract, состояние настройки OCR,
  пояснение о сохранении оригиналов и ручной сверке текста.

Видны настроенные режимы исследователя/критика и ожидание экспертной разметки.
Наличие ключа и успешная проверка доступа — разные состояния. Ключи не выводятся
в API и не вводятся в браузере: настройки находятся в локальном `.env`.

В библиотеке можно загрузить известное дело из КАД либо вставить текст вручную.
Загрузка ограничена бюджетом первоначальных документов; об оставшихся актах
показывается предупреждение. Результаты исследования показывают цитаты, историю,
OCR и сохранённые оригиналы, включая ограничения доступных источников.

## Проверка и сопровождение

Браузерный сценарий проверяет загрузку шрифтов и маленьких значков, подключение
карточек готовности, темы, библиотеку, историю, цитаты, фильтр, уточнения,
панель этапов и отсутствие ошибок JavaScript. Используются синтетические материалы.
Изображения CI сохраняются в артефактах; передача base64-снимков в журналы удалена.

Общий скрипт тестов использует PostgreSQL только при явном TEST_DATABASE_URL;
рабочая DATABASE_URL не подставляется автоматически. Исторические отчёты и корпус
сохранены, поскольку на них опираются воспроизводимые оценки.
