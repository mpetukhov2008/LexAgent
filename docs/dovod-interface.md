# ДОВОД — обновление интерфейса

9 ноября 2026. ДОВОД — название пользовательской платформы; имя репозитория
LexAgent и контракты API сохранены.

## Внешний вид

- Тёмная тема используется при первом посещении независимо от системной темы.
  Явный выбор светлой/тёмной сохраняется в localStorage.
- Крупные основные шрифты, контрастные карточки, синие и мятные акценты.
- Стартовый экран с авторским SVG-силуэтом Москва-Сити. Нет внешних изображений,
  шрифтов или сетевых зависимостей для оформления.
- Ссылка поддержки ведёт точно на https://t.me/m_petukhov_2008;
  переход открывает новую вкладку, сообщение автоматически не отправляется.
- Подпись: «Создано в МИФИ. Сначала думаем. Потом доказываем».
- Стартовый экран не имитирует регистрацию и не запрашивает пароль. Вход открывает
  существующее локальное пространство; реальной многопользовательской авторизации нет.

## Процесс исследования

progress.js вычисляет состояния из статуса задания и фактического журнала событий.
experience.js показывает текущего агента, завершённые этапы, последние действия
и время с начала запуска. Это не оценка оставшегося времени и не прогресс по токенам.

Нажатие этапа объясняет его задачу, но не объявляет его работающим и не запускает
сетевые вызовы. Неисполненные этапы не становятся завершёнными. Остановка,
необходимость уточнения и ошибка сохраняют самостоятельные состояния.
Повтор сравнения после критики виден как возврат к соответствующему агенту.

Панель обновляется существующим опросом API. Для внешнего исследователя и критика
добавлены явные события начала/конца, для получения PDF — событие чтения источника.
Процент вероятности победы, выдуманный ETA и искусственная постепенная загрузка отсутствуют.

## Доступность и анимации

Переключатели имеют доступные названия и состояние, этапы доступны с клавиатуры,
текущий этап отмечен aria-current. Нажатие даёт короткую анимацию, работающий агент —
пульсирующее кольцо. prefers-reduced-motion отключает анимации и плавные переходы.
Тема и вход работают также при недоступном хранилище браузера.

## Проверка

Шесть автономных JS-проверок охватывают очередь, текущего агента, одиночный разбор,
уточнения/остановку/ошибку, возврат критика и неполные результаты источника.
Браузерный сценарий проверяет вход, сохранение темы, переходы к цитатам,
мобильное меню, источник событий, доступный режим уменьшенного движения и ошибки JS.
Обработка в визуальном сценарии проверяется на явно синтетическом потоке событий;
платные внешние API не вызываются.
