# Проверка реализуемости

Дата: 30.10.2026. Итог: можно начинать ограниченный MVP; сквозная автоматическая система и качество аналогов еще не подтверждены.

## Уточнение темы

По запросу пользователя первая категория изменена на споры о копировании контента карточек маркетплейсов. Живой поиск в КАД по номерам подтвердил А70-7129/2024 и А22-2425/2025; ссылки и ограничения проверки — в [тематическом плане](marketplaces.md). Ниже сохранен первоначальный технический эксперимент по поставке как история проверки интерфейса, а не подтверждение тематического поиска по маркетплейсам.

## Что действительно проверено

| Проверка | Результат | Что это означает |
|---|---|---|
| Открытие официальной КАД | Доступна страница с фильтрами по участнику, суду, номеру и дате | Есть официальный интерфейс поиска карточек |
| Открытие официального Банка решений | Доступен поиск по тексту и категории | Подходит как источник кандидатов для тематического поиска |
| Живой поиск в браузере | Введено «неоплата поставленного товара», нажата кнопка «Найти»; показано «Найдено 209817 документов», первая страница содержит 25 позиций | Форма реально вернула выдачу; счетчик относится к документам, не уникальным делам |
| Проверка выдачи | Видны номера дел, суды, даты, виды актов и ссылки на PDF | Есть реквизиты для дальнейшей проверки; тексты и применимость не проверены |
| Документация Parser API для ras.arbitr.ru | Описаны поиск по тексту и получение PDF, требуется ключ | Возможен адаптер, но документация не подтверждает доступность по конкретному тарифу |
| Локальные учетные данные | В прежней папке нет `.env`, переменная `PARSER_API_KEY` отсутствует | Аутентифицированный запрос API не запускался |
| Код прежнего проекта | В `lexagent/app/parser_api.py` есть получение карточки по номеру и PDF через сторонний сервис | Это заготовка для повторного использования после проверки, не готовый поиск аналогов |

Первая страница живой выдачи включала, например, [А11-8063/2025](https://kad.arbitr.ru/Card/b888e0ed-0bc6-4a09-9012-292c070bb689), [А43-32401/2025](https://kad.arbitr.ru/Card/b38ad6cd-d228-4856-a0d0-7c5bccf86d65) и [А39-3691/2026](https://kad.arbitr.ru/Card/cda40b84-a5a6-42ef-ae9d-3aede61e8b4f). Это свидетельства выдачи, не рекомендованные аналоги. Среди заголовков есть оспаривание сделки должника: совпадения поисковых слов требуют содержательной фильтрации. Содержание актов в этой проверке не изучалось.

Для повторения: открыть ras.arbitr.ru → «Текст документа» → ввести запрос без кавычек → «Найти». Число результатов и их порядок могут измениться.

## Источники и ограничения

- [КАД](https://kad.arbitr.ru/) — карточки дел и движение по инстанциям.
- [Банк решений](https://ras.arbitr.ru/) — интерфейс поиска по тексту судебных актов, виду и категории спора.
- [Документация Parser API для Банка решений](https://parser-api.com/ras-arbitr-ru) — сторонний сервис, а не официальный API суда. Описывает `search` с параметром `text` и `pdf_download`. Для RAS признак успеха — `done=1`; прежний адаптер КАД проверяет `Success=1`, поэтому напрямую переиспользовать его нельзя.
- [Документация Parser API для КАД](https://parser-api.com/kad-arbitr-ru) — получение карточек и документов.

Публичный официальный API с гарантированным массовым доступом этой проверкой не установлен. Доступность браузерного поиска не равна разрешению на массовое копирование. У поставщика требуется проверить права хранения и индексации, квоты, стоимость и условия использования. Закрытые материалы дела не входят в предполагаемый корпус.

## Что пока не доказано

Получение полного PDF по живому API; полнота и устойчивость выгрузки; правильность извлечения текста; учет отмен и изменений решений; качество смыслового поиска; стоимость одного полного исследования; экономия времени юриста. Ни одной метрики качества продукта пока нет.

## Обязательный технический эксперимент в первую неделю

1. Получить доступ к поиску RAS и детализации КАД с согласованными условиями хранения. Не публиковать ключи и запросы с ними в журналах.
2. Выполнить 10 заранее составленных запросов по копированию контента карточек маркетплейсов из тематического плана, сохранить параметры, время, коды ответа и реквизиты результатов. Каждого кандидата проверить в КАД.
3. Получить 30 уникальных актов; проверить открытие PDF, текстовый слой и соответствие номера/даты карточке. Для сканов проверить OCR отдельно.
4. На пяти делах проверить связку первой инстанции и последующих актов. Не приравнивать наличие более позднего определения к отмене решения.
5. На десяти фабулах сравнить простой поиск по словам и поиск с дополнительным ранжированием. Юрист вслепую оценивает результаты обоих вариантов.

Условие продолжения онлайн-версии: подтверждены условия доступа; не менее 27 из 30 актов удалось получить и прочитать, все сбои классифицированы; есть проверяемые ссылки и данные для восстановления цепочки. Порог — проектный, еще не достигнут. Если эксперимент не проходит, ограничить источник или объем, а не маскировать пробелы текстом модели.

Основной риск — данные и качество сопоставления. Увеличение числа агентов само по себе его не устраняет.
