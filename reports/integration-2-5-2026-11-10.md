## Корпус и оценка

Подготовлены 40 гипотетических задач, привязанных к трём историческим актам;
27 dev и 13 test. Все имеют status=pending и назначение participant_5. Это не
40 независимых реальных дел и не экспертно размеченная выборка. Исторические
материалы не названы подтверждёнными оригиналами: проверка прямой загрузки трёх
старых ссылок не дала пригодных исходных PDF.

Есть пустой шаблон ручных оценок, инструкция, сохранение имени/времени/основания
проверки, валидатор групп дел и отказ от экспертного режима для pending-меток.
Для расширения корпуса реализован build_case_corpus с сохранением оригиналов
через Parser API. Участнику 5 передана [инструкция](../docs/participant-5-annotation-handoff.md).
Если участник не обладает предметной юридической компетенцией, перед публикацией
юридического качества нужна дополнительная проверка юристом.

Выполнен предварительный поиск по известному пулу:

| Часть | Запросов | Дел в пуле | Lexical P@5 / R@20 | Multi-query fusion P@5 / R@20 |
|---|---:|---:|---|---|
| dev | 27 | 3 | 0.2 / 1.0 | 0.2 / 1.0 |
| test | 13 | 3 | 0.2 / 1.0 | 0.2 / 1.0 |

Эти числа вычислены по автоматическим **предварительным** меткам. При одном
положительном деле и выдаче короче пяти Precision@5 ограничен знаменателем 5;
Recall@20 при пуле всего из трёх дел почти неинформативен. Доказательством качества
поиска или преимущества полной системы эти результаты не являются.
Время сохраняется в JSON конкретного прогона; оно относится к небольшому локальному
пулу, не к задержке живых источников.

Отдельно реализован запуск lexical / without_critic / full на одном замороженном
пуле с временем, модельными вызовами, токенами, версиями корпуса/промптов и
материалами для ручной оценки. Живые вызовы требуют локального ключа GigaChat.
Смысловую правильность отчётов нельзя вывести из retrieval-метрик.

## Проверки

Локально Windows / Python 3.12: 168 серверных тестов пройдены; девять PostgreSQL
тестов оставлены для реальной БД в GitHub Actions. Браузерный сценарий и шесть
проверок событий интерфейса также выполнены. Итог CI конкретного коммита
фиксируется в интеграционном PR перед слиянием.

Проверены настоящая русская OCR-страница, архив/дедупликация/версии PDF, хеши,
ошибки и бюджет повторов, страницы RAS, события и инстанции, неверный номер дела,
несуществующая цитата, инструменты критика, запуск контрпримеров, повторное
сравнение, ограничения отчёта, восстановление без повторного поиска и миграция.

Аудит обновлённого lock-файла: 62 зависимости, известных уязвимостей не найдено.
Первоначально выбранная библиотека изображений дала 39 предупреждений и полностью
исключена из зависимостей и кода. OCR передаёт PDFium-растр как PGM напрямую в
Tesseract; тест не нуждается в библиотеке изображений. Windows-установщик Tesseract
и языковая модель сверяются по опубликованным/зафиксированным SHA-256.
Это не гарантия отсутствия неизвестных уязвимостей нативных компонентов.

Статический анализ Bandit: пять предупреждений низкой важности проверены вручную.
Два относятся к URL авторизации/пустому токену в существующем GigaChat-клиенте,
три — к импорту subprocess и двум запускам доверенного OCR-движка. Shell не
используется, аргументы передаются списком, пути создаёт сервер, время ограничено.

## Что нельзя считать завершённым без внешней проверки

1. Экспертная разметка и юридическая приёмка: назначены участнику 5, не подделаны.
   Нужны проверенные оригиналы, больше независимых дел и слепые новые test-задачи.
2. Актуальная доступность Parser API/GigaChat и живой сквозной прогон зависят от
   локальных ключей. На момент подготовки отчёта ключи отсутствовали. Создан
   игнорируемый пустой .env; значения никогда не включаются в Git.
3. Юридическая окончательность, полнота внешней базы и точный объект отмены
   не гарантируются снимком API или моделью. Неисследованное показывается явно.
4. Смысловой индекс/pgvector относится к отдельной работе поиска и не добавлен
   под видом реализации участников 2/5. Публичный многопользовательский сервер
   с аутентификацией и изоляцией данных также не заявляется.

Рабочая техническая реализация и воспроизводимые инструменты готовы к использованию;
объявлять весь юридический результат экспертно проверенным пока нельзя.
