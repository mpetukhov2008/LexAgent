## Живые проверки

1. GigaChat OAuth прошёл с настоящим ключом.
2. Агент 1 прошёл живой разбор синтетического примера: 6 сведений, 1 уточнение.
   Артефакт: `gigachat-live.json`. Это ранний прогон адаптера; поле model в этом
   артефакте пустое из-за исправленной позже ошибки отображения метаданных.
3. Все пять базовых ролей выполнили по inspect_context и submit_result через
   настоящий GigaChat. Источник намеренно синтетический. В раннем прогоне проверка
   отсеяла две неточные цитаты. Текущий `gigachat-pipeline-live.json` отражает
   более поздний повтор через LangChain, описанный выше. Это не проверка
   юридической релевантности или доступа к реальной судебной практике.
4. Запуск через HTTP API с настоящим PostgreSQL записывается в
   `postgres-gigachat-api-live.json`. Именно этот файл содержит итоговые статус,
   карточку и журнал последней сквозной проверки.
5. Оба переданных Parser API ключа получили HTTP 403 / error_code 40301 на
   ras_arbitr_api/search и arbitr_api/details_by_number. Ключи не включены в отчёт.
   Причина отклонения аккаунтом поставщика не установлена. Проверка с другого IP
   не выполнялась. Код запрещённого IP в документации поставщика — 40303.

## Что исправлено по результатам живых проверок

- Разворачивание вложенных JSON Schema для функций GigaChat.
- TLS: официальный сертификат загружается только в SSL-контекст проекта,
  без отключения проверки и без изменения системного доверия.
- GigaChat иногда завершал разбор после чтения без сохранения фактов. Теперь
  finish отклоняется, пока каждое поле не получит факт или явный вопрос.
- Базовое сравнение не получает оценку применимости без проверенной цитаты.
- Ошибка внешнего поиска сохраняется как частичный результат, не пустая практика.

## Ограничения результата

Нет подтверждённого живого поиска через Parser API, размеченного реального корпуса,
замеров Precision/Recall, векторного индекса, OCR и автоматической проверки всей
истории инстанций. Этапы 2–6 ограничены и предназначены для дальнейшей работы команды.

Сервис локальный и однопользовательский. Он не готов к публичному многопользовательскому
развёртыванию. Текстовый импорт помечен как пользовательский; оригинальность не проверяется.

Секреты находятся в `.env`, каталог data исключён из Git. Проверка исходников,
тестов, документации, отчётов и скриптов на присутствие текущих секретных значений
не выявила совпадений. `.env.example` содержит только пустые поля секретов.
