## Живой Yandex: конкретный блокер

Пользователь предоставил ключ и идентификатор. Первый ответ API сообщил несовпадение идентификатора с каталогом сервисного аккаунта и указал корректный каталог. Локальная настройка исправлена по этому ответу. Следующий запрос вернул отказ в доступе к ресурсу каталога. Успешная генерация или вызов инструмента живой моделью **не выполнены**.

Нужна проверка роли `ai.languageModels.user` сервисного аккаунта на каталог и области ключа `yc.ai.languageModels.execute`. Права аккаунта автоматически не менялись. После исправления доступа выполнить полный синтетический разбор в режиме Yandex и дополнить этот отчет. Demo не подменяет успешную проверку API.

## Что означают эти результаты

Проверена программная работоспособность первого этапа на синтетических входах. Не измерены качество свободного извлечения живой Alice AI, точность юридического анализа и качество поиска аналогов. Агенты 2–6 и поиск КАД здесь не запускались. Локальная SQLite выбрана для предварительной защиты; PostgreSQL не подключен.

## Воспроизведение

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check app tests scripts
.\.venv\Scripts\python.exe -m ruff format --check app tests scripts
.\.venv\Scripts\python.exe scripts/demo.py
```

Результаты синтетических прогонов и журнал каждого шага: `reports/demo/complete.json`, `missing.json`, `conflict.json`. Скрипт их воспроизводит без сети и без ключа.
