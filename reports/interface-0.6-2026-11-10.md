# Довод 0.6: интерфейс, документация и проверка проекта

10 ноября 2026. Основа — main `179d37d` с объединёнными PR №1–4.
Новых открытых PR на момент начала работы не было. Приватность репозитория
подтверждена через GitHub API. Изменения подготовлены отдельно в `ui/dovod-refresh`.

## Интерфейс

- Manrope для форм/текста, Unbounded для заголовков; кириллица, локальные variable WOFF2.
  Общий объём шрифтов — около 306 КиБ; полные лицензии сохранены.
- Небольшие стилизованные векторные обозначения WB/OZON рядом с названиями площадок,
  включая исходные сведения результата. Исходный текст и доступные названия сохранены.
- Сохранены структура кабинета, город, цвета, адаптивность и две темы.
  Nuclear IT Hack использован как ориентир выразительной типографики, без копирования ресурсов.
- Отдельные карточки GigaChat, КАД/RAS и OCR. Наличие ключа не выдается за успешную
  проверку соединения; кнопки внешних проверок недоступны без настройки ключей.
- Показаны оригиналы, история, смысловой критик и ожидание экспертной разметки;
  добавлен быстрый переход к проверке готовности и понятные названия новых действий агентов.
- README полностью переписан по восьми пунктам владельца: название «Довод», команда
  «Поколение Степика», задача и все пять участников указаны в начале.

## Интеграция и настройки

КАД интегрирован через Parser API, а не прямой официальный API суда. Есть карточки,
акты инстанций/событий и PDF; тематический поиск идёт через Банк решений. В основной
исследовательской цепочке КАД/RAS объединяются для снимка истории дела. В интерфейсе
есть загрузка известного дела в библиотеку и отдельная диагностика двух сервисов.

Обнаружено и исправлено устаревшее поле версии контракта в публичной конфигурации:
теперь передаётся фактическая 2.1. Добавлены безопасные сведения о возможностях и
лимитах, без значений ключей. Ручной импорт КАД ограничен research_acts (по умолчанию
8 PDF) и сообщает об оставшихся документах. Отключённый OCR обозначается отдельно
от наличия установленного движка.

## Где искали ключи

Проверены локальные .env и переменные процесса, файлы проекта и доступные копии
участников, исходный архив, патч и история конфигурации Git. Примерно 276 текстовых
файлов/версий проверены на присваивания известных переменных, без вывода значений.
Действующие ключи Parser API/GigaChat не найдены; найденные непустые значения — тестовые.

Исторические отчёты живых прогонов сохранены: они объясняют, почему прежний разработчик
мог говорить о работающем доступе. Они не содержат готовых действующих настроек.
Доказательств удаления ключей при этой интеграции нет. Другие компьютеры и окружение
прежнего разработчика недоступны этой проверке. Живой прогон без ключей не заявляется.

Код и документы публикуются в приватный репозиторий. .env, рабочая БД, установленные
зависимости/движок и оригиналы PDF остаются локально; шаблон .env.example в Git сохранён.
Экспертная разметка отложена по указанию владельца, предварительные метки не подтверждались.

- Удалён ui_previews.py и шаг отправки base64-снимков в CI-журнал. Скриншоты остаются
  обычными загружаемыми артефактами, диагностическая функция сохранена.

  Установленный Tesseract и языки, .env, база, оригиналы, исходники, ТЗ и корпус сохранены.
- Исторические отчёты не удалялись: на текст одного из них опирается retrieval-корпус.
