## Что добавлено

- START_DOVOD.cmd в корне: вход для двойного щелчка Windows 10/11 x64.
- scripts/start_dovod.ps1: проверка Python, отдельное окружение, точные зависимости,
  создание .env только при отсутствии, подготовка OCR и запуск браузера.
- Если Python отсутствует, используется полный официальный архив Python 3.14.10,
  распаковываемый в data/. SHA-256 взят из официального windows-манифеста.
  Системный установщик, регистрация Python и изменение PATH не требуются.
- Блокировка одновременной подготовки, сохранение настроек, повторное использование
  окружения. Ошибка остаётся в окне, её можно прочитать и передать тимлиду.
- app/desktop.py: сервер привязан к 127.0.0.1, порт резервируется до запуска.
  Занятый чужой порт пропускается. Повторный запуск открывает только сервер
  этого проекта из этой папки; готовность проверяется до открытия браузера.
- Остановка — Ctrl+C в окне запуска. Проверочный режим останавливает сервер сам.
- README.md, идентичный README.txt и короткий START_HERE.txt включены в GitHub ZIP.
- Отдельная проверка GitHub Actions создаёт ZIP из коммита и запускает именно
  START_DOVOD.cmd в пути с пробелами/кириллицей, с новым Python, OCR и повторным стартом.

Источник Python: https://www.python.org/ftp/python/3.14.10/windows-3.14.10.json
Закреплённая сумма: cc28026a650970cc1570bb127312f1f9634eb67abfe157ae6ca1acbbc627d091.
Сама среда, архив Python и пакеты не включаются в исходный GitHub ZIP.

## Что доступно после установки

SQLite, интерфейс, учебные сценарии, ручной импорт текстов, история и экспорт.
Распознавание сканов требует установленного OCR; если Windows отменяет установку,
демо и текстовые PDF сохраняют работоспособность. Внешние источники и модель требуют
локальных ключей. Экспертная разметка и юридическая приёмка остаются будущей работой.

На первом запуске нужны интернет, доступ на запись и свободное место. Прокси,
антивирус, запрет сценариев/загрузок, длинные пути и отсутствие разрешения на OCR
могут помешать. Рекомендуется короткая папка. Для macOS/Linux есть ручные команды
в README; Windows-запускатель не заявляется универсальным автономным приложением.
