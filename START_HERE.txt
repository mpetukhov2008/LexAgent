ДОВОД — Поколение Степика

1. Распакуйте ВЕСЬ ZIP в отдельную папку на Windows 10/11 x64.
2. Дважды нажмите START_DOVOD.cmd.
3. Дождитесь установки компонентов: в первый раз нужен интернет.
4. Когда откроется сайт, выберите «Сначала попробовать на примере».
5. Окно запуска оставьте открытым. Для остановки нажмите Ctrl+C.

Если Python не установлен, запускатель скачает и распакует официальный Python
в папку проекта, проверив контрольную сумму. Системная установка Python не нужна. Для OCR Windows может запросить разрешение. Если его не дать,
демонстрация и текстовые PDF работают, распознавание сканов — нет.

Без ключей работают интерфейс, учебные примеры, ручное добавление текстов,
история и экспорт. Для GigaChat и КАД нужны GIGACHAT_AUTH_KEY и PARSER_API_KEY
в локальном .env. Ключи в ZIP не входят. После изменения .env перезапустите окно.

Если сайт не открылся, прочитайте сообщение в окне запуска; оно не закроется
при ошибке. Адрес может отличаться от 8010, если этот порт занят.
Не запускайте файл внутри архива. Не переносите .venv с другого ноутбука.
Антивирус, запреты на установку, отсутствие интернета или свободного места могут
помешать подготовке. Для macOS/Linux смотрите README.txt или README.md.

README.txt содержит полный README проекта. Ручная юридическая проверка корпуса
будет выполнена позже; выводы системы остаются предварительными.
