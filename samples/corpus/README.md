# Кандидаты для разметки — не юридически проверены

`manifest.json` фиксирует три акта и тексты страниц, уже присутствовавшие в
`reports/ras-gigachat-verified-live.json`. Само имя исторического отчёта **не означает**
экспертную юридическую проверку, проверку актуальности или доступности источника сейчас.
Релевантность каждому виду копирования карточек должна быть определена разметчиком;
отрицательные или неприменимые примеры не исключаются заранее.

В манифесте закреплены источник, реквизиты и URL, идентификатор акта, количество
страниц и SHA-256 канонического JSON массива страниц (UTF-8, `ensure_ascii=False`,
`sort_keys=True`, `separators=(',', ':')`). SHA-256 всего исторического отчёта позволяет
проверить вход. Оригинальные PDF в отчёте отсутствуют, их хеши пока `null`: это хеш
текстового представления, не PDF. Повторно извлекать и проверять исходные PDF следует
только при разрешённом доступе; сохранить байты и хеш отдельно, сверить страницы с
оригиналом, источник, даты и всю цепочку инстанций. Обезличивание и условия обработки
документов необходимо оценить перед распространением или разметкой.

Для воспроизведения использовать зафиксированный в Git отчёт и манифест; без сетевых
обращений сравнить SHA-256 файла и страниц по описанному правилу. Для каждого акта
эксперт отдельно размечает тип высказывания, требования, возражения, доказательства,
обстоятельства, мотивы и результат, сверяя акт и страницу; не превращайте отсутствие
последующего акта в утверждение об окончательности решения.

Для исходного отчёта в `.gitattributes` закреплены переводы строк LF: это сохраняет
проверяемые байты и SHA-256 при checkout на Windows и Linux.
